# 霓虹铁拳：对决 Neon Knuckles: Versus

原创 1v1 街头格斗游戏。后端 Erlang/OTP（cowboy WebSocket，服务器权威，30 tick/s），前端 three.js。
角色、名字、招式和美术均为原创，沿用了上一版《霓虹铁拳》的模型、场景、特效和音效。

## 启动

- Windows：双击 `start.bat`（需要 Erlang/OTP 26；会自动下载 rebar3 并编译，然后打开浏览器）。
- Linux / macOS：`./start.sh`
- 手动：`rebar3 shell`，然后访问 http://localhost:8090/

## 模式

| 模式 | 说明 |
| --- | --- |
| 对战 CPU | 自选对手和难度（新手 / 普通 / 困难 / 高手），三局两胜 |
| 街机闯关 | 依次挑战其余三人、自己的镜像，最后是关底 Boss「OVERCLOCK」；CPU 逐关变强，输了原地续关 |
| 本地双人 | 同一台电脑两人对打 |
| 联机对战 | 输入相同房间号进入同一擂台，先到的两人对打，其余观战 |

## 操作

| | P1 | P2 | 手柄 |
| --- | --- | --- | --- |
| 移动 / 跳 / 蹲 | A D / W / S | 方向键 | 摇杆、十字键 |
| 拳（连按三段） | J | 小键盘 1 或 `,` | X |
| 踢（挑空；蹲下 = 扫腿） | K | 小键盘 2 或 `.` | A |
| 技（特殊技） | L | 小键盘 3 或 `/` | B |
| 投 | I | 小键盘 5 或 `'` | Y |
| 必杀（能量满 100） | U | 小键盘 4 或 `;` | RB |

- 防御：按住远离对手的方向。站防挡不住下段（扫腿、滑铲），蹲防挡不住跳攻击，投技不能防；被投瞬间按投可以拆。
- 疾走 / 后撤：快速双击前 / 后。疾走中按拳是冲刺攻击。
- 空中按拳是跳攻击，按踢是下砸。
- 特殊技：`技` 飞行道具，`前 + 技` 突进，`下 + 技` 对空或下砸。命中普通技后可以立刻取消成特殊技或必杀。
- 场地中途会落下「霓虹核心」，抢到立得 50 能量。能量跨局保留。
- H 出招表，M 音乐，Esc 回大厅。

### 关底 Boss「OVERCLOCK」

只在街机第 5 关出现，由 CPU 操控（练习：浏览器地址改成 `http://localhost:8090/?cpu=boss`，再选「对战 CPU」）。
血 1450，重拳、跳起踩地（落地一圈下段冲击波，蹲防或跳起躲）、蓄力冲撞、扔扳手、必杀「超频连锤」。
出招带霸体、挑不起来，但它**不会蹲**：扫腿、滑铲这类下段一定打得中。
